# Security

Please report a vulnerability privately, through GitHub:
**Security › Report a vulnerability** on this repository.
Don't open a public issue for it.

Language Coast has no server. The reports that help most
are about:

- how API keys are stored on the phone and kept out of
  backups and logs,
- importing untrusted files (Anki `.apkg`/`.colpkg`,
  backups, CSV),
- what is sent to AI providers, and when.

Fixes go into the next release; there is one supported
version, the latest.
