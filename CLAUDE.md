## Agent skills

### Issue tracker

Issues live in GitHub Issues for `Andreas-Erick/LanguageCoast`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels are used as-is: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` at the repo root (created when first needed) plus `docs/adr/`. See `docs/agents/domain.md`.
